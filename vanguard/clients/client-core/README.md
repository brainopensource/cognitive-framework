# `@vanguard/client-core`

Headless core package for Vanguard runtime clients. Provides contract types, vg.4 parser, RFC 8785 Ed25519 signer, live UDS/feed transports, replay/scenario adapters, and run-view state reducers.

Shared by Ink TUI (`@vanguard/cli`) and Standalone GUI IDE (`vanguard-gui`).
