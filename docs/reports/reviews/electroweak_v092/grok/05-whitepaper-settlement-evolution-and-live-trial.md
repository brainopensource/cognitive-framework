# Settlement Before Scale: An Audit of Coding Agency on the AETHER Substrate

## Abstract

This paper is a non-canonical audit of the coding agent that the AETHER
substrate presently instantiates, written as a specialist review for a
release owner who must decide what to build next and what to refuse. The
subject is not a vendor clone and not a new ontology of roles. The subject
is a pack, a profile, four mediated verbs, and one EpisodeEngine, running
on a domain-blind kernel whose Trusted Computing Base remains bounded. The
central claim is that session success is a product of conditional
probabilities of honest progress given honest prior state. If inner
settlement is leaky, every outer loop multiplies false completions. The
living execution board already encodes the correct overlay, namely
instrument identity, truthful completion, durable resume, epoch-bound
context, multi-file change closure, single-engine control, and only then
meta, specialists, campaign, memory, and official measurement. Sibling
reviews from independent auditors converge on this overlay if they are
sequenced and diverge only if they are treated as competing next sprints.
A live greenfield trial on 2026-09-04, run identifier gf-orders-001,
against deepseek-v4-flash through OpenRouter, confirmed that the gated
product arm will abandon rather than admit a lying completed state when
no patch exists, and also confirmed that the model’s intended reads were
never dispatched because fenced JSON in prose was classified as finish.
The implication for evolution is therefore not a Svelte specialist, not
Chimera, and not an outer director. The implication is to make settlement
the inner loop, to recover tool dialect into effects, to feed implicated
and greenfield facts that already exist as modules into the admitter, and
to dogfood tiny Python oracles until that loop cannot lie. Official
benchmark percentages are measurements under G-3 and are not the
definition of done. This document authorizes nothing. It deposits the
maximum forensic and programmatic material this folder should hold so
that a later implementer does not have to reconstruct the argument from
chat.

Meta must not admit completed and must not grow budget.

The original Grok and Opus forensic reviews were written against
5243866bc169 on feat/strongforce_beta_release_v093. Between that pin and
the live trial pin ffc3dc926e80 the branch continued; the trial therefore

not a nine-point-five percent model failure.

## 2. The product thesis and the dual mission

AETHER is an event-sourced substrate for agentic computation. An agent is
not a persistent in-memory object. An agent is identity, policy, an
event-derived projection, and an execution boundary. The dual mission is
to prove a coding vertical on one engine and to keep the same substrate
usable for other agents. The CLI is a client of ApplicationService. Apps
remain thin on purpose. If a new agent type required a large application
layer, the substrate would have failed to generalise.

SOTA for this tree is therefore not a tweeted leaderboard. SOTA is a
structurally untrusted model, on one EpisodeEngine, that cannot admit
completed without a typed exterior oracle; that can resume a crash
without duplicate effects; that can change a large implicated set without
mutating tests; that can scaffold greenfield so stubs fail before
implementations pass; and that can run a week of work as a campaign of
honest episodes rather than one amnesiac transcript. Public DeepSWE
percentages measure that later. They do not define it.

The reliability identity used throughout is the product over turns of the
probability of honest progress given honest prior state. Improving a
single turn while allowing finish on prose drives the product to zero.
Outer loops, memory promoters, and evolutionary directors inherit that
zero. This is why settlement is the inner change and why the outer change
is forbidden until settlement holds.

## 3. The agent as it is, not as the README wishes

Composition is ApplicationService to HarnessSession to EpisodeEngine to
Kernel.dispatch along S0 through S12. The product coding arms named
vg-code-fast, vg-code-balanced, and vg-code-max declare the same four
verbs: fs.read, fs.search, patch.apply, and proc.exec with an argv
allowlist of git, pytest, ruff, and python3. They reuse the vg-code-default
prompt, tools, policies, and the single skill pytest-green. They differ
only in the harness name field of the manifest. They are aliases, not
phenotypes. Calling max does not enlarge the brain. It selects the gated
name that actually runs the admitter.

AdmissionGate defines VerificationReceipt.passed as exit code zero and
executed_test_count greater than zero. Unknown runners parse to zero.
Finish is retried when the admitter rejects, provided the admitter runs.
The function admission_required exempts vg-code-default and vg-code-lex
and otherwise gates whenever patch.apply is among declared verbs. The set
ADMISSION_GATED_HARNESSES lists product names and is unused. The product
arms are therefore gated by capability derivation. The default pack, which
those arms compose for prompts and tools, is exempt if invoked under its
own name. That exemption is pinned by RF-25 successor tests. Shrinking it
is a governance decision named T-04, not a silent edit.

Context is one ContextCompiler with L1 through L3 frozen at construction,
σ in L4, dialogue in L5, distiller caps on tool bodies, and an omission
ledger. IndexPort is observation only. It ranks nothing. It exposes
index, files, symbols, dependencies, tests, and repo_map. It has no
callers method. Reverse dependencies must be derived in pack policy.
SemanticTaskState folds from the ledger. MS-RESUME is CLOSED. Skills are
names in L3 with bodies on read. The phase ladder exists in agency but
product arm directories have no tool-policy.json, so the product path is
an ungated loop. Enabling inspect-forbids-exec would break reproduce-first
and must not become default.

Mechanisms that exist and are not wired into session admit include the
tamper shield, implicated-set builder, and greenfield vacuity policy.
Two-phase commit exists for multi-file adapter writes. Single-file writes
remain sequential with a syntax observation. Kernel contains no ast.parse.
Forge and Chimera exist and are not the product path. Campaign and
outer_loop packages do not exist. Memory SPI exists and product wiring is
gated. Meta exists as a powerless advisor.

## 6. Empirical trial: gf-orders-001

On 2026-09-04 a greenfield challenge was materialised under
/tmp/aether-gf-challenge, outside the git tree, so that dogfood would not
contaminate the repository with n equals one reports. The workspace
contained TASK.md, data/orders.csv with three line items, and
test_report.py asserting total_revenue of 75.50, units_by_sku of five
WIDGETs and one GADGET, write_summary emitting revenue and top_sku, and a
non-stub check. Pre-run unittest produced four errors, all
ModuleNotFoundError for report. That is a correct red oracle.

The stock CLI path vanguard code run with non-interactive true maps to
kernel benchmark mode that fails closed on approval-gated proc.exec. An
unattended coding trial therefore cannot use that flag if verification is
required. The trial invoked ApplicationService.run with profile local,
manifest vg-code-max, model_port openrouter, planner_model
deepseek/deepseek-v4-flash-0731, allow_paid true, interactive true,
autonomous_approval true, max_turns twenty, run_id gf-orders-001. Operator
keys already existed. Wall time was approximately thirteen seconds.

The RunResult outcome was abandoned, turns three, projections containing
only a complete record with the same outcome. The workspace still had no
report.py. Post-run unittest remained four errors. The SQLite WAL ledger
contained eighty-eight events. Kind counts were dominated by plugin
lifecycle. There were three TurnStarted, three ProposalProduced, one
EpisodeCompleted with reason abandoned, and zero EffectRequested or
EffectCompleted. Admission on the gated arm did not emit completed. The
tree did not change. This is failed for the task and honest for the gate.

Turn zero’s model note said it would start by reading the test file and
the data file. The engine recorded reason finish and action null. Turn
one’s note contained a fenced JSON object with action read and path
data/orders.csv. The engine again recorded finish. Turn two’s note
contained fenced JSON to read test_report.py with kind effect. The engine
again recorded finish. EpisodeCompleted followed. The model was not
silent. The ACI did not parse prose JSON into fs.read. Dialect recovery
that exists for truncated streams and fences did not, in this trial,
promote those fences into dispatched effects.

The disposition is therefore failed, not undeterminable. The instrument
ran. The model produced three proposals. The proposals were classified as
finish. No effect occurred. The gate refused to call that success. A
weaker path, vg-code-default exempt, could have called it completed. This
trial used the gated name on purpose. Historical frontier_v090 artifacts
of NO_PATCH with completed_without_source_patch at a different pin remain
frozen logs. They are consistent in kind with this trial’s missing patch,
and they are not this trial’s numbers.

## 7. What the trial implies for dialect, tool choice, and prompts

The prompt already tells the model to emit exactly one tool call per
turn. The model emitted English and then a markdown JSON example of a
read. That is a common DeepSeek-class failure mode: the tool schema is
not used, or tool_choice is not required, or the translator only accepts
native tool_calls and leaves fenced JSON in the note field. T-21 landed
typed failure classes. The gap observed here is not a missing type name.
The gap is that a recoverable dialect was treated as a successful finish
proposal rather than as a malformed effect to retry.

The correction is not a longer system prompt apologising for the absence
of ls. The correction is to treat a fenced action object as a candidate
effect, to reject finish when the note contains an action block and no
tool call, and to return a typed recovery that offers only the intended
verb after showing the current file. Parallel to that, unique-match
str_replace in the adapter and glob or list as observation sinks reduce
the need for the model to narrate reads it cannot issue. Those adapter
changes must not wait for a second engine. They also must not ship as a
twenty-verb ontology that bypasses admit.

Prompt-only control remains a weak lever because the model is
structurally untrusted. Restricting what it may say does not hold.
Kernel.dispatch is the path. If finish can be proposed from text that
contains an intended read, the path is not being used. That is an inner
loop defect with a high posterior after this trial.

## 8. Greenfield as a scientific protocol, not a product SKU

Greenfield is empty-tree construction under a failing oracle. It is not
npx create-svelte. The product allowlist cannot install Node packages.
The in-tree analogue that can work is Python http.server plus static HTML
plus unittest, as in benchmarks/greenfield/greenfield-v0450-webapp and
greenfield-api-html. A later pack may add node and npm to proc.exec. That
is a profile delta. It is not a second runtime and not a Svelte agent
class.

The protocol is an empty workspace, a TASK.md that names files, behavior,
and the exact verify command, and tests that fail on stubs. The agent
writes through patch.apply, one file or one atomic node per turn, then
runs python3 -m unittest. Pandas is optional and often unavailable inside
containment. Stdlib csv is the honest first case. The trial used that
shape and still produced no file, which isolates ACI and settlement from
task difficulty. Difficulty was low. Dispatch did not occur.

Pack policy already names vacuous oracles. Session evidence currently
aliases structural and behavioral passed to verification.passed and never
sets oracle_failed_on_stub. Prompt text that says do not read first
fights the policy that wants scaffold and stub-fail. For multi-day
greenfield the file DAG belongs in σ, which already has TaskStep. Toy
TASK.md heuristics must not be universal law.

## 9. Brownfield blast radius, tamper, and implicated tests

Hard brownfield is a signature change whose callers were not opened and
whose tests were not the ones run. The implicated-set builder exists.
Session does not pass implicated_files or reverse dependencies into pack
completeness, so surface equals changed. Empty primary plus coverage
ratio 1.0 is already rejected in policy if those observations arrive.
They do not. Tamper freeze exists and hashes tests via IndexPort. Session
does not call evaluate on admit. An agent can edit the assertion. T-07
typed verification subject is open, so python3 -c print OK remains a
hole on paths that reach it.

The inner program is therefore wiring, not invention. Pass IndexPort
tests and dependencies into completeness. Enumerate tamper subjects from
that set, not from glob of test. Bind argv digest, workspace digest, and
task digest as the verification subject. Move read-before-edit from
finish-time MODIFIED_FILE_NOT_INSPECTED to the effect boundary so the
tree stays clean. Recover PATCH_PREIMAGE_MISMATCH by forcing fs.read of
that path rather than fuzzy relocating hunks. Indentation is semantics.
Silent mis-apply is a lying state.

Two-phase commit for N greater than one is MECHANISM. The write the
model actually uses is often N equals one. Either extend atomic commit
to that path or batch a DAG node so sequential syntax receipts cannot
look like success for a multi-file intent. Kernel AST remains forbidden.

## 10. Context, cache, compact, distill, and long sessions

Prefix-stable L1 through L3 is the correct cache law. Breakpoints are not
emitted. A prefix-stability regression test must land before
cache_control, because a breakpoint on a drifting prefix pays the write
and never hits. Retrieved ranking must not splice into L1 through L3.
Agent-issued index queries return in L5. Distillation is already at the
effect boundary in spirit. Digests are not memory. The model must read to
recover. Compaction must not LLM-summarise away falsified hypotheses.
If HypothesisRejected events are never emitted, L4 has nothing to pin.
Honest producers for the fold that already exists are harness
engineering, not a new agent.

MS-RESUME being CLOSED means a crash can restore episode_id and σ. It
does not mean a four-hundred-turn chat is the long-run architecture.
Long runs should become many admitted episodes. Operator cancel is kernel
CANCELLED. Checkpoint UX is T-59 and is a client of the ledger. Worktrees
keep a crashed writer from poisoning the parent. None of this is a second
EpisodeEngine. All of it is early if child completed can still be prose.

admit.

## 13. How to build agents this week without a new type

Next is not a new agent type. The coding agent is pack, profile, four
verbs, and a thin CLI. Do not start Chimera. Do not start a Svelte
specialist. Do not start an outer director. The proving case that fits
HEAD is Python greenfield with a failing oracle the operator wrote.

The operator initialises an empty directory, not this repository, writes
TASK.md and a failing test, runs vanguard init, and invokes the gated
preset max with a live model port. Default model-port fake is a stub.
Without OpenRouter, a local llama.cpp endpoint, or an equivalent live
provider, the run is plumbing. Fast, balanced, and max are the same
tools. Max is the gated name. Do not invoke vg-code-default for product
dogfood. It can finish with no files.

Treat CLI completed as a hypothesis. Confirm files on disk. Confirm the
oracle went red then green. Confirm the ledger shows patch.apply and a
real runner. If before equals after, the run lied or never wrote. After
gf-orders-001 we also know that abandoned with three finish notes and no
effects is an honest terminal and a failed task. That is the correct
pair.

The stock code run non-interactive flag is the wrong unattended switch
for coding, because proc.exec is approval-gated. Unattended dogfood
should pass autonomous_approval with interactive true at the
ApplicationService boundary until the CLI exposes that pair without
collapsing to benchmark fail-closed. Documenting this seam is part of
framework evolution. Hiding it behind a prompt is not.

Svelte and npm remain a future allowlist. Static HTML with a Python
oracle is the web analogue that the current verbs can in principle
touch, once dialect actually dispatches.

## 15. Framework evolution: primitives already present

The hexagonal lattice, domain-blind kernel with a line budget, typed
effects, monotonic attenuation, ledger as fold, one EpisodeEngine, packs
and manifests as composition, AdmissionGate, optional IndexPort and
MemoryPort, grants, exterior evaluator identity, and spawn as the only
recursive primitive already constitute a framework that can build agents.
What is missing for a thin universal actor protocol is honest child
completed, a content-addressed mailbox as data not as a second store, a
director that only reads the ledger and spawns sessions, operator
interrupt as CANCELLED, and manifest extends so a second actor is a
delta rather than a twelve-file copy.

The authoring cost of a second agent is today too high because manifests
copy twelve component paths and tools are not shared. Inheritance in
manifests is a small composition improvement with large generality
payoff. It must not become a fourth graph that declares the order of work
before work runs. derive_phase is already that mistake in miniature.

## 16. Scientific operating system

Improvement is known when a freeze binds n, models, stop rule, subject
SHA, and suite digest before spend; when canary dispositions occupy the
set positive, negative, undeterminable, invalid; when trajectories are
the ledger; when compiled context is reconstructable as fold of events
plus omissions; and when paired statistics run on exact-subject rows.
G-3 remains: local, cassette, LAM, and n equals one files never become
official scores. Cassette rows that look like 1.0 in the same schema as
live rows must carry provenance that aggregators cannot ignore.

The trial gf-orders-001 should be cited as a log, not committed into
benchmarks/artifacts as another report_v3. Logs belong under the
workspace .vanguard directory and remain gitignored. That discipline is
how the evidence directory stops dominating every census with interactive
debugging.

## 17. Limitations of this paper

PASS. The live trial is n equals one on one model and one brief. Free
band models were not compared. Sandboxed and hermetic profiles were not
compared with local. The CLI non-interactive seam was inferred from
source and from the choice to use ApplicationService. Octopus SHA

LDA doctor was degraded in sandbox sessions and is not used as authority.
The white paper is non-canonical. Promotion into tasks.md remains a human
ratification.

## 18. Conclusion

The substrate is rare and should not be rebuilt. The coding agent is a
gated four-verb loop whose default pack can still lie if invoked by name,
whose tamper and implicated modules are unwired, and whose live trial
shows a model that narrates reads the engine records as finish. Outer
loops, new phenotypes, and npm allowlists do not fix that. Settlement,
dialect-to-effect, and tiny Python oracles do. If the three reviews are
complementary, they are staged. If they compete, they are sequenced.
What is good but early is parked. What breaks the kernel or the honesty
of completed is rejected.

The next operator action is another empty directory, another failing
oracle, preset max, a live model, and a ledger read, while engineering
lands T-04 as governance and wires the admitter that already exists. The
next non-action is a new agent type.

## Appendix D. Reliability identity once more

R is the product over t of the probability of honest progress at t given
honest state at t minus one. A finish proposal that changes nothing is
not honest progress even if the model’s English is correct. A completed
status on that proposal would have set a factor to a lie and poisoned
every later campaign node. Abandoned preserves R. Failed task, preserved
R, is the only acceptable pair until dialect dispatches and settlement
still refuses empty patches. That pair is the scientific result of
gf-orders-001 and the programmatic reason this folder exists.

## 20. Multi-file edits, long context, and long runs as three problems

Conflating multi-file, long context, and long runs produces sprawl.

in the implicated set. Public signature changes require call sites in
the same transaction. Syntax failure of file four of five must roll

selection and prefix problem. The compiler already knows where layers
break. The adapter does not emit cache breakpoints. Distillation must

identity, not in the index. Long runs are a process and campaign

after a token ceiling is already closer to the architecture than
compacting one transcript into mush.

self-harm. SectionAddress already exists. A sectioned viewer is an
inner capability with high leverage and no kernel change. A 100-line

attention. The trial never read orders.csv, which is twenty bytes of
