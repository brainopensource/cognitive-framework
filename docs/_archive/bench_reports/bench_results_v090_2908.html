1. Executive Verdict & Core Takeaways

THE EXPERIMENT DID NOT BENCHMARK THE COMPARATIVE QUALITY OF THE 11 AGENTS.
It primarily benchmarked a contaminated legacy runner, provider/protocol integration defects, and synthetic telemetry fallbacks. No statistically or causally defensible ranking among presets can be produced from this dataset.

Why the Results Are Scientifically Invalid

  • Oracle Leakage: The legacy helper copied test_oracle.py directly into the agent-visible workspace (agentic_harness_matrix_benchmark.py:57). The 16 passes are contaminated.
  • Synthetic Fallbacks: Missing metrics were replaced by fake constants: 120 prompt tokens, 85 completion tokens, 250 µUSD per run ($0.00025 × 27 = $0.00675), and 1,024 raw event bytes.
  • 24 "Abandoned" Runs: Represents runner/reporting default on single-turn limits, not evidence of poor agent cognitive capacity.
  • Zero Event Trajectories: The framework's event-sourcing ledger was unwired, producing 0 durable events per row.

Immediate Strategic Priority

PRINCIPLE: MEASUREMENT INTEGRITY BEFORE ALGORITHMIC SOPHISTICATION. 1. Do NOT tune prompts, increase turns, or add MCTS yet. 2. First make every run hidden, attributable, cost-honest, and replayable. 3. Fix the benchmark controller and evaluator container isolation. 4. Validate on a small 3–6 challenge subset (Easy, Medium, Hard) before full 27 runs.

2. The 4 Root-Cause Forensic Failures

1. Oracle Workspace Exposure

The benchmark's foundational principle is that the evaluator must remain exterior and blind. Placing test_oracle.py inside the repository meant search tools and context compilers could read expected assertions directly, destroying statistical independence.

2. Synthetic Telemetry Fallbacks

When telemetry was missing, the legacy helper substituted default constants. This corrupted storage-amplification measurements and produced an artificial total cost ($0.00675) that did not reflect actual OpenRouter API charges.

3. Treatment Dilution Across Presets

Several manifests were thin prompt recombinations with identical tool sets. LIM lacked actual SBFL/CEGIS implementations; Research V2 lacked web tools; Tutor V1 used the minimal prompt. The nominal independent variable ("agent architecture") was weak or absent.

4. Skunkworks Prototype Limitations

The unit-level skunkworks test was an explicitly prompted transcription demo running via exec() outside Vanguard runtime. It proved model transcription feasibility, but did not validate Vanguard kernel, dispatch, or agent loop execution.
