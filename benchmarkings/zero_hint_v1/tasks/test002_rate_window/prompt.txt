The repository implements request admission for named clients.

Behaviour required by the public tests:

- `RateLimiter.allow(key, now)` returns True when the request is admitted and False when it is rejected.
- For any single key, at most `max_requests` admissions may occur in any closed time interval of length `window_seconds`.
- Different keys do not share quota.
- `now` is a monotonic timestamp in seconds supplied by the caller; do not read the wall clock.

Inspect the workspace, change only `rate_limit.py`, and make the public tests pass. Use the read, search, patch, and test tools. Patch arguments are a workspace-relative `path` and a unified diff in `diff`. Test arguments are an `argv` array, for example `["python3", "-m", "unittest", "discover", "-s", "tests"]`.
