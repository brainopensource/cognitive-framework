## 2. BLOCKER 1 — recursion is implemented but **unreachable**

Sprint 8's sentence: *"A parent episode spawns a child under an attenuated grant and a child lease."*
**This is true of the test suite and false of the system.**

| Probe | Result |
|---|---|
| `grep -rn "\.spawn(" vanguard/` | **no production call site** |
| `.spawn(` in `test/` | 6 call sites |
| `ProposalKind` members | `EFFECT`, `FINISH`, `ABSTAIN`, `ESCALATE` — **no `SPAWN`** |
| `spawn` in manifests / packs / `schemas/` | **none** |
| `SpawnResult` consumers | only its own definition in `state.py` |

A model therefore **cannot propose a spawn**, and no Python path calls it. The only way to reach `spawn` is a test constructing an engine directly.

The code agrees. Both docstrings still say so, and both are still accurate:

- `engine.py:17-19` — *"Depth-1 … this engine never re-enters itself."*
- `state.py:167` — *"Immutable episode state. Depth-1: an episode spawns no sub-episode."*

These are the exact lines the Sprint 8 README quoted as the thing this sprint would falsify. They were never touched.

**Why this blocks Sprint 9.** `S9-B-01` requires three packs differing on **≥3 DNA dimensions**, and recursion/isolation is the dimension `VG-03 §10.3` calls *"the primary mechanism."* Measuring packs that cannot spawn measures the wrong system. `spawn` is currently dead weight carrying an unearned `[DONE]`.
