# ADR-0016: Operators are data in the competence graph, not functions in the loop

**Reasoning.** A loop hard-coding "planning" can never replace its planner. This is what makes operator-level improvement reachable at all

**Reversal condition.** Never without abandoning self-improvement above the prompt level
