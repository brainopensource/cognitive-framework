Create the file `solution.py` in the workspace root. It must define one function.

`balances(lines)` takes a list of transaction strings and returns a dict mapping
account name to integer balance.

Each transaction has the form `FROM>TO:AMOUNT`, for example `alice>bob:50`.
- The amount moves out of FROM and into TO.
- Account names may have surrounding whitespace, which is not part of the name.
- Amounts are whole numbers.
- Every account that appears, on either side, is present in the result.
- Accounts that never appear are absent from the result.

Rules for bad input, each raising `ValueError`:
- A line that does not contain exactly one `>` and one `:`.
- An amount that is not a whole number, or is negative.
- An empty account name once whitespace is removed.

An empty list returns an empty dict.

The tests in `tests/` cover the basics. Make them pass.
