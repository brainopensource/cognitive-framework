[EDGE-CASE BEHAVIOR]
1. **Empty Content**: If `content` is an empty string (`""`), return an empty list `[]`.
2. **Trailing Commas**: If a record ends with a comma (e.g., `",,"`), the last field should be an empty string `''`.
3. **Quoted Empty Fields**: If a field is quoted but empty (e.g., `""`), it should be an empty string `''`.
4. **Quoted Fields with Content**: If a field is quoted and contains content, the quotes should not appear in the output (e.g., `"hello,world"` should output `["hello,world"]`).
5. **Escaped Quotes**: If a quoted field contains two consecutive double quotes (e.g., `"hello""world"`), they should be interpreted as a single double quote character (e.g., `["hello"world"]`).
6. **Newline Handling**: Both `
` and `
` should be treated as record separators, ensuring that line breaks within quoted fields do not create new records.
