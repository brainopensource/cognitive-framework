# ADR-0011: Capabilities carry resources, not only verbs

**Reasoning.** A verb-only "read-only" child can read the evaluator bundle, the policy configuration and the signing keys. All read-class, all permitted

**Reversal condition.** Never — this is `05 [S1(a)]`

**Owner · status.** Tech Lead · accepted
