4. Deep Root-Cause Code Forensics & Defects

1. Conversational Context Flattening (L5 Dialogue Formatting)

In vanguard/packages/adapters/models/openrouter.py and context/compiler.py, dialogue history blocks (L5) are converted to raw user messages:

# openrouter.py:284 for block in context.get("blocks") or (): label = block.get("label", "") content = block.get("content", "") messages.append({"role": "user", "content": f"[{label}] {content}"})

Defect: The model never sees its own prior assistant tool calls. The chat stream consists of multiple consecutive user messages, destroying conversational tracking and triggering infinite fs.read loops.

2. Aggressive 15s Timeout & exc.fp None Bug

In tools/runners/run_swe_challenge.py and openrouter.py:

# run_swe_challenge.py:58 BENCHMARK_REQUEST_TIMEOUT_SECONDS = 15.0 BENCHMARK_MAX_RETRIES = 1 # openrouter.py:232 except urllib.error.HTTPError as exc: return int(exc.code), resp_headers, exc.read() or b""

Defect: Generation latency exceeding 15.0s causes socket closures. When exc.fp is None, calling exc.read() crashes with AttributeError: NoneType object has no attribute read, masking the real timeout.

C. Insights & Recommended Fixes for Live Matrix Execution

  • Subprocess Test Execution Overhead: In verification-heavy benchmarks, pytest subprocess executions account for 67% – 72% of runtime latency (~100ms per test invocation). This is cleanly bounded and safe from race conditions due to isolated temp workspace allocation.
  • Falsification & Safety Proofs: The intentional failure of negative controls (such as t0-dogfood-bug-001 and incomplete SemVer diffs) proves that Vanguard's exterior oracle verification correctly fails closed and records explicit FAILED_ORACLE receipts without framework crashes.
  • Live Model Execution Strategy: Real model latency on OpenRouter (typically 1.5s – 8s per turn) dominates live runs. To optimize live runs, presets should use streaming tool parsing and sequence full multi-file patches within single turn intervals where feasible.
